Технологический стек
Backend: ASP.NET Core 8.0 Web API, JWT аутентификация
Desktop: WPF (.NET 8.0), MVVM
База данных: Microsoft SQL Server
Тестирование: MSTest (модульные), интеграционные тесты
Система контроля версий: Git / GitHub
Система "АгроКонтроль"
Разработана автоматизированная система управления производством для предприятия по производству средств защиты растений (гербициды, инсектициды, фунгициды).

Модули системы:
AgroControlAPI — бэкенд-сервер, обеспечивающий хранение данных, бизнес-логику и API
TechnologistModule — рабочее место технолога (управление рецептурами и техкартами)
LaboratoryModule — рабочее место лаборанта (контроль качества сырья и продукции)
OperatorModule — рабочее место аппаратчика (выполнение технологических операций)
