## 📚 Описание проекта

**AgroControl** — это комплексная информационная система для предприятия по производству гербицидов, инсектицидов и фунгицидов. Система объединяет три ключевых роли в едином цифровом пространстве:

- 👨‍🔬 **Технолог** – управление рецептурами, технологическими картами, заказами и партиями.
- 🧪 **Лаборант** – контроль качества сырья и готовой продукции, ведение протоколов испытаний.
- ⚙️ **Аппаратчик** – пошаговое выполнение технологического процесса, телеметрия экструдера.

Взаимодействие осуществляется через единый REST API (ASP.NET Core 8.0) с JWT-аутентификацией. Все клиентские приложения построены на **WPF (.NET 8.0)** по архитектуре MVVM.

## 🧩 Функциональные возможности

### 👨‍🔬 Модуль технолога
- Ведение карточек продукции, сырья, оборудования
- Создание и версионирование рецептур (контроль суммы компонентов = 100%)
- Разработка технологических карт и шагов
- Формирование производственных заказов и партий
- Мониторинг выполнения, просмотр отклонений

### 🧪 Модуль лаборатории
- Контроль качества сырья (входной контроль)
- Испытания готовой продукции после производства
- Автоматическая проверка параметров по нормативам
- Принятие решения: допуск / блокировка
- Генерация протоколов испытаний (PDF)
- История всех испытаний

### ⚙️ Модуль аппаратчика
- Отображение активных производственных партий
- Пошаговое выполнение технологической карты
- Ввод фактических параметров, фиксация отклонений
- **Телеметрия экструдера** (имитация температуры, давления, скорости шнека в реальном времени)

## 📦 Быстрый старт (локальное развёртывание)

1. Клонируйте репозиторий:  
   `git clone https://github.com/your-username/AgroControl.git`
2. Откройте решение `AgroControl.sln` в Visual Studio 2022.
3. Настройте строку подключения в `appsettings.json` проекта `AgroControlAPI` (по умолчанию используется LocalDB).
4. Выполните миграции:  
   `Update-Database` в Package Manager Console (проект API).
5. Запустите API (нажмите F5).
6. Запустите любой desktop-модуль (TechnologistModule, LaboratoryModule, OperatorModule).
